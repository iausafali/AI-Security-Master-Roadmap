## 🛡 The S++++++ Proof-of-Mastery Standard

A phase is never marked complete on lecture-completion or course-certificate grounds. The non-negotiable exit sequence applies to every flagship project:

1. **Derive:** Reconstruct the underlying math/logic from first principles, unaided.
2. **Implement:** Build it from scratch — zero wrapper shortcuts.
3. **Benchmark:** Compare against a real, independent baseline (NumPy, scikit-learn, published CVEs).
4. **Break:** Attack or stress your own implementation until it fails.
5. **Patch:** Fix the vulnerability, then re-attack to confirm the patch holds.
6. **Document:** A written artifact another systems engineer can audit without asking questions.
